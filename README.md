# Himnos

Himnario digital estático desarrollado con HTML, CSS y JavaScript vanilla.

## Objetivo

Proveer una interfaz simple, rápida y legible para lectura y búsqueda de himnos, optimizada para escritorio y dispositivos móviles.

## Características

- Sitio completamente estático
- Compatible con GitHub Pages
- Datos desacoplados en JSON
- Búsqueda por título, número y contenido
- Soporte dark mode
- Diseño responsive
- Sin dependencias externas

## Estructura

```text
index.html
css/style.css
js/app.js
data/himnos.json
```

## Decisiones de diseño

El proyecto prioriza:

- simplicidad
- rapidez de carga
- legibilidad
- máximo aprovechamiento del espacio de pantalla
- facilidad de mantenimiento

Se evita el uso de frameworks para mantener una base liviana y portable.
